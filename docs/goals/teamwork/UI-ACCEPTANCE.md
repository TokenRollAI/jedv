# UI 验收清单（用户最新修订）

以下要求覆盖早期仅绑定已有 Leader 的默认创建设计；既有功能验收不抵扣这些新增项。实现中只做功能与视觉验证，全部功能结束后再集中深度 review。

- [ ] 默认直接开始新 Task：输入任务、工作区和 Agent，Host 可靠启动新 Leader 并建队；无需先选现有 Leader。已有会话作为次级入口保留。重复提交/断连重试不重复开终端，失败保留任务草稿与操作身份。
- [ ] 创建页复用现有 PromptInput、Picker、Button 等组件；无重复标题、原生 radio、textarea 拖拽角或大段技术说明。参考 `docs/design/o1GQt.png`。
- [ ] Teamwork 与 Projects 复用同一个分组标题样式，字体、字号、字重、字距、行高、折叠图标与间距一致。
- [ ] 设备状态栏始终贴侧栏左下角；两目录全部折叠、长列表滚动、窗口变矮、Butler 系统空间打开时均不移位。参考 `YQJBx.png`。
- [ ] 底栏 Agent Island / Menu bar activity 快捷开关移入既有设置 → 外观 → 智能体活动，保留功能和已有偏好。
- [ ] Butler 统一烟斗图标（现有 `GiSmokingPipe`），覆盖桌面与移动端，保留清晰 aria/tooltip。
- [ ] 应用内原生 select/option 全部替换为主题一致的 Select/Popover/Command（移动静态页用等效可访问列表框），验证 keyboard/focus、空值、长标题、滚动与窄侧栏。初次扫描桌面8文件10控件，移动2控件；实施后全局复查新增文件。
- [ ] Team mail / Shared memory 与 Butler 标签页统一使用现有 TabsList/TabsTrigger 风格，邮件计数使用统一 Badge。
- [ ] 每张成员卡的状态图标固定右上角、同一内边距；不随 terminal/stop 按钮数量错位。标题、品牌图标、皇冠、任务与位置对齐，终端动作保留正文右侧。
- [ ] 新增文案全部使用 Lingui 英文 ID、18 catalog 完整；真实 GUI 复验暗色/浅色与移动视口。

## Butler 对话页二次设计（用户截图反馈）

- [ ] 不保留空白待办主区挤压右侧窄聊天列；进入对话后主内容优先供阅读与输入，保留明确返回建议/待审批入口。
- [ ] 复用项目现有Markdown与消息/输入组件，正文前景对比清晰，用户/Butler消息层次明确，长代码/链接不横向溢出。不要直接显示Markdown原始格式符号。
- [ ] 对话历史选择、新建、关闭/返回只保留必要入口，长标题截断但可访问；无重复Ask按钮、口号与大段空状态说明。
- [ ] 保留已有聊天、用户设置、草稿与审批真实状态；布局优化不删除历史或擅改后端/模型提示。由Gemini/Kimi交叉讨论、Pencil先行再实现。

### Butler session 三轮结论

- [ ] 无常驻session下拉/标题管理，默认稳定对话；历史和新话题按需。聊天主视图参考Wd34v。
- [ ] 桌面/手机/CLI共享稳定默认入口；历史读写或审批请求不抢当前；新话题接纳与幂等回放不导致指针倒退；有草稿/在途请求不被跨端切换覆盖。
- [ ] 历史及原审批归属保留，模型读取有界上下文和真实业务状态，不把旧助手文字或写操作当新指令。程序化审批不制造可见session。
