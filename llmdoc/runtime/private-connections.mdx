# 私网直连、转发与重连

私网连接以一个受验证的 origin 和 host PSK 为能力边界。桌面先验证地址与凭证格式，再使用有限时、禁止 redirect 的 host 查询探活；只有成功后才在 main 保存该连接 token。连接失败不能留下“已连接”的授权状态。

## origin 与 token

用户连接入口只接受不含路径、查询、fragment 或内嵌凭证的 origin。127.0.0.1 可用 HTTP，其他入口要求 HTTPS 的 Tailscale `.ts.net` 地址。PSK 不含空白。HTTP Bearer 与 WS token 都由 host 的同一 PSK provider 做等长、恒时比较；机器标识用于调用上下文，不代替认证。

main 按 origin 保存 ForwardTokens，并区分 coordinator 与 authenticated-private 来源。coordinator 登记仍须实时匹配其当前 endpoint/secret；显式私网连接则只有真实 workspace.list 鉴权握手成功后才能登记，包括独立 loopback Host。不能把所有回环地址强制归属于 coordinator，也不能仅凭未经握手的 token 缓存授予连接权限。

每次私网握手拥有独立 generation；disconnect、clear、coordinator 重新登记或同 origin 新握手都会撤销旧 attempt，晚到成功不能重新授权。重连先撤销旧来源、关闭该 origin 的 transport/mux 并释放转发 lease，再进行新握手；失败不恢复旧授权。disconnect 同样撤销来源和 pending attempt、关闭流并释放 lease，避免 UI 断开后旧流仍可访问。

## 端口转发是工作区能力

一个 `/fwd` WebSocket 承载该工作区的多个 TCP 流，帧协议有握手、流数、窗口和数据上限。host 每次 OPEN 都检查端口扫描器当前是否将目标端口归属于请求工作区；已建立 host 连接不等于任意端口访问权。流量窗口和 TCP backpressure 必须端到端传播，不能用无界队列吸收慢读者。

desktop 按地址和 workspace 复用 mux；token 或 CA 改变时淘汰旧会话。单请求取消只能清理无其他 pending 或 active stream 的会话，不能切断共享连接里的其他用户请求。远端不支持协议、拒绝凭证和未授权是不同可解释失败，不应一律当网络离线。

## relaySocket 是共用的直连重连实现

`createRelaySocket` 的历史名称不代表托管云运行依赖。当前终端和 eventBus 在直连地址上共用它：每次拨号重新取得 URL 与 token，避免重连一直使用过时签名；显式 reconnect 或 close 可以打断 retry 等待。

默认 `maxEnqueuedMessages=0`，断线时输入不缓存重放。旧命令在恢复后突然发送会产生新的执行副作用，不能为了“可靠传输”改成自动重放。eventBus 的 watch interest 则是可重建的订阅状态，open 后重新登记，二者必须区分。

`probeRelayHost` 仅识别 `/hosts/<id>/` 可选兼容路径；普通直连 URL 立即返回 null，不发云端探测。null 表示没有该诊断信息，不能据此宣称已认证、主机离线或请求成功。

通用 HTTP 批流适配器用 POST query 避免大输入撑爆 GET header。旧 host 明确拒绝 method override 时，只对 query 回退一次 GET；连接失败清除该 endpoint 的降级记忆，让替换后的 host 重新探测。不要将这一兼容分支写成云服务前置条件。
